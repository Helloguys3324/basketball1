HOW TO USE THIS FOLDER:
========================
Drop your 8 (or more) MrBeast scam images directly into this folder!
Supported formats: .png, .jpg, .jpeg, .webp

When anti_scam_bot.py starts:
1. It will automatically load every image in this folder.
2. It converts each image into perceptual vectors (pHash and dHash).
3. It saves the vectors into 'scam_vectors.json'.
4. Any user posting identical or similar copies of these images on Discord will have their message auto-deleted immediately!
